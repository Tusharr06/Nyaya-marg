# Nyaya Marg ⚖️

**Nyaya Marg** (Path to Justice) is a comprehensive legal assistant application built with Flutter, designed to bridge the gap between citizens and the legal system. By leveraging AI-powered tools and real-time analytics, Nyaya Marg empowers clients with legal knowledge and provides lawyers with advanced case management capabilities.

## 🚀 Vision

To democratize access to legal information and streamline the justice delivery process through technology, making legal aid accessible, transparent, and efficient for everyone.

## ✨ Features

### 🧑‍⚖️ For Clients
- **Know Your Rights Hub**: A dedicated section to educate users about their fundamental rights and legal protections in various scenarios.
- **AI Chat Assistant**: An intelligent chatbot powered by **Google Gemini** to answer legal queries, draft basic documents, and provide instant guidance.
- **Legal Tools**: Access to a suite of utility tools designed to simplify legal processes for everyday users.
- **Profile Management**: Securely manage personal details and legal history.

### 🏛️ For Lawyers
- **Justice Graph Analytics**: Advanced data visualization tools to track case progress, predict case duration, and analyze backlog risks.
- **Case Management Dashboard**: A centralized hub to manage client cases, schedules, and documents efficiently.
- **Professional Profile**: Build and showcase a professional portfolio to potential clients.

## 🛠️ Tech Stack

- **Framework**: [Flutter](https://flutter.dev/) (Dart)
- **Backend**: [Firebase](https://firebase.google.com/)
  - **Authentication**: Secure user login and role-based access control.
  - **Firestore**: Real-time NoSQL database for flexible data storage.
  - **Storage**: Secure cloud storage for legal documents.
- **AI Integration**: [Google Generative AI](https://ai.google.dev/) (Gemini) for intelligent legal assistance.
- **UI/UX**: Custom Material 3 design with [Google Fonts](https://fonts.google.com/) (Poppins) for a modern, accessible interface.
- **Platforms**: Android, iOS, Windows, Web.

## 📱 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed on your machine.
- [Firebase CLI](https://firebase.google.com/docs/cli) for backend configuration.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/nyaya-marg.git
   cd nyaya-marg
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Configure Firebase**
   Ensure you have your `firebase_options.dart` file set up. If not, run:
   ```bash
   flutterfire configure
   ```

4. **Run the App**
   ```bash
   flutter run
   ```
